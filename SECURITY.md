# Security Policy

This repository contains public framework documentation. It should not contain product secrets, customer data, private deployment artifacts, cryptographic keys, proprietary schemas, or implementation internals.

## Reporting Security Issues

If you find sensitive information accidentally published in this repository, please report it privately.

Contact: security@neoxfortress.com

If that mailbox is unavailable, contact NeoXFortress through https://neoxfortress.com.

## Public Issues

Please do not open public GitHub issues containing:

- Vulnerability details
- Exploit instructions
- Private keys
- Customer information
- Proprietary product implementation details
- Sensitive deployment details

Use private disclosure first.
