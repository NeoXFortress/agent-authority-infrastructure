# NIST SP 800-53 to AAI Concepts

This conceptual crosswalk focuses on control families commonly relevant to auditability, authorization, accountability, and review.

| Control Family | AAI Relevance | Evidence Concept |
| --- | --- | --- |
| AC - Access Control | Action boundaries and tool authorization | Mission authority decision |
| AU - Audit and Accountability | Action-level event evidence | Signed receipt and ledger entry |
| CA - Assessment, Authorization, and Monitoring | Security review and closeout evidence | Evidence pack |
| IA - Identification and Authentication | Agent identity context | Agent registry and IdP binding |
| SI - System and Information Integrity | Detection of unexpected action patterns | Denied-action and review records |

This is not a control implementation statement. It is a discussion mapping.
