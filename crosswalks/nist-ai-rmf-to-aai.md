# NIST AI RMF to AAI Concepts

This conceptual crosswalk maps NIST AI RMF-style governance concepts to AAI evidence concepts.

| AI RMF Function | AAI Contribution | Example Artifact |
| --- | --- | --- |
| Govern | Define mission authority and action boundaries | Mission authority policy summary |
| Map | Identify tools, data boundaries, users, and operational context | Agent action map |
| Measure | Capture decisions and outcomes per action | Signed action receipts |
| Manage | Deny, escalate, revoke, or approve actions | Decision records and review queue |

AAI does not replace AI RMF. It can provide runtime evidence that supports AI RMF-aligned governance narratives.
