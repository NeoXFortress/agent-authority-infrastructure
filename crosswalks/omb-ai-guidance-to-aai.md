# OMB AI Guidance to AAI Concepts

This conceptual crosswalk maps federal AI governance themes to AAI evidence concepts.

| Governance Theme | AAI Concept | Evidence Question |
| --- | --- | --- |
| Accountability | Signed action receipt | Can reviewers see which agent attempted which action? |
| Governance | Mission authority policy | Is there a defined boundary for what the agent may do? |
| Risk management | Deny / human-review decisions | What happens when an action exceeds scope? |
| Acquisition discipline | Closeout evidence pack | Can a pilot produce reviewable artifacts? |
| Public trust | Tamper-evident evidence | Can records be inspected after the fact? |

Use this as a starting point for discussion, not as a compliance claim.
