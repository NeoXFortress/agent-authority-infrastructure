# Use Cases

These examples are illustrative. They are designed to show where Agent Authority Infrastructure fits, not to define a product schema.

## 1. RMF / ATO Evidence Support

An AI agent helps a program team draft SSP narratives, POA&M updates, control summaries, or closeout evidence.

AAI helps define:

- Which source repositories the agent may read
- Which control families are in scope
- Whether the agent may write draft outputs only
- Which actions require human review
- What evidence should be preserved for the ISSO, ISSM, AO, or assessor

Outcome: the agent can assist with documentation while the program retains evidence of what the agent was allowed to access and what it attempted to do.

## 2. Controlled Document Review

An AI agent summarizes, tags, or extracts information from controlled documents.

AAI helps define:

- Which folders or collections are in scope
- Which document labels are allowed
- Whether export is permitted
- Whether sensitive references trigger review
- Which denied access attempts should be recorded

Outcome: document review can remain bounded by mission and data scope.

## 3. Procurement and Vendor Communications

An AI agent drafts vendor questions, summarizes RFP language, or prepares package materials.

AAI helps define:

- Which solicitation materials are in scope
- Whether external email is allowed
- Whether draft language requires approval
- Which attachments can be accessed
- Which actions should be held for human review

Outcome: program teams can use AI assistance without treating the agent as an uncontrolled external communicator.

## 4. Internal Support Agent

An AI agent answers employee support questions by consulting approved internal systems.

AAI helps define:

- Which employee data can be queried
- Which fields are out of scope
- Whether write-back is allowed
- Which requests require human review
- What evidence is preserved for audit

Outcome: support workflows can be automated without allowing the agent to exceed approved data or tool boundaries.

## 5. Security Operations Triage

An AI agent summarizes alerts, enriches findings, and recommends next actions.

AAI helps define:

- Which enrichment tools are allowed
- Whether containment actions require human approval
- Which systems may be queried
- Which actions are denied outright
- How evidence is exported to downstream security systems

Outcome: SOC teams can use AI assistance while preserving action accountability.
