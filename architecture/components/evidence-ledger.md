# Evidence Ledger

The Evidence Ledger is the conceptual plane where action receipts are preserved for later review.

The ledger should support tamper-evident review, not merely event storage.

Conceptual goals:

- Preserve allowed actions
- Preserve denied actions
- Preserve human-review actions
- Support closeout evidence packs
- Support downstream SIEM, GRC, audit, and RMF workflows

This document does not publish a product data model.
