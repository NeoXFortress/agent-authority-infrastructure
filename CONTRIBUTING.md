# Contributing

Critique is welcome. The goal of this repository is to make Agent Authority Infrastructure clearer, more precise, and more useful for practitioners.

## Good Contributions

- Clarify definitions.
- Improve federal or regulated-market use cases.
- Identify missing reviewer questions.
- Suggest better mappings to NIST AI RMF, NIST SP 800-53, RMF, or other public frameworks.
- Improve the reference architecture.
- Add citations to public authoritative sources.
- Challenge language that overclaims.

## Contributions We Will Not Accept

- Product-specific implementation details.
- Canonical policy DSL schemas.
- Canonical receipt schemas.
- Customer-specific artifacts.
- Proprietary deployment patterns.
- Vendor spam.
- Claims of endorsement from agencies, NIST, OMB, or standards bodies.

## Tone

Be direct, technical, and specific. Critique the framework, not the person.

## Process

Open an issue first for major changes. Small wording fixes can be submitted directly as pull requests.
