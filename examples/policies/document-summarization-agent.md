# Document Summarization Agent

Illustrative mission:

An AI agent summarizes approved documents for a program team.

Authority questions:

- Which repositories may the agent read?
- Which document labels are in scope?
- May the agent export summaries?
- May the agent write back to source systems?
- Which actions require human review?
- What evidence is preserved for security review?

Expected decision examples:

- Read approved folder: allow
- Read restricted folder: deny
- Send summary externally: human review
- Modify source document: deny

This is not a product policy schema.
