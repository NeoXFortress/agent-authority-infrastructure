# Zenodo Release Notes

Use this directory to track DOI publication steps.

## v1.0.0 Release Plan

1. Publish this repository to GitHub.
2. Connect the GitHub repository to Zenodo.
3. Create a GitHub release tagged `v1.0.0`.
4. Let Zenodo archive the release and assign a DOI.
5. Update:
   - `README.md`
   - `CITATION.cff`
   - `CITATION.bib`
   - `papers/the-case-for-agent-authority-infrastructure.md`
   - `docs/01-definition.md`
   - NeoXFortress website

## Recommended Zenodo Title

Agent Authority Infrastructure: A Framework for Runtime Authority, Approval, and Evidence in AI Agents

## Recommended Resource Type

Publication / Working paper

## DOI Language

After Zenodo assigns a DOI, say:

> This framework is citable via Zenodo DOI.

Do not say:

> Peer reviewed.

Do not imply NIST, OMB, agency, or standards-body endorsement.
